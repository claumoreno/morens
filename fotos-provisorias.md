# Fotos provisorias

Fotos de referencia (Pinterest u otras fuentes sin permiso de uso) que se usan **solo** para ver cómo queda el sitio privado en Vercel.

**Ninguna puede quedar en la página el día del lanzamiento.**

## Reglas

1. Cada foto provisoria va en la carpeta `fotos/provisorias/`.
2. En el código se usa con la función `provisoria("archivo.jpg", "tono", "alt")`, y la línea de arriba lleva el comentario:
   ```js
   // PROVISORIA - reemplazar antes de lanzar
   ```
3. Cada foto se anota en la tabla de abajo: archivo, dónde se usa, de dónde salió y con qué se va a reemplazar.
4. Antes de lanzar: buscar "PROVISORIA" en todo el proyecto y vaciar la carpeta `fotos/provisorias/`. No debe quedar ninguna.
